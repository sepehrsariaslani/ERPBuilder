# Composition and visual rhythm

Composition controls how the eye moves through a page. Apply it after information hierarchy is correct.

## Page rhythm

Build a repeated vertical rhythm:
1. page identity and navigation;
2. current status and primary action;
3. decision-critical summary;
4. main working surface;
5. supporting detail / relations / activity.

Do not make every section equally loud. Alternate emphasis and quiet space so the user can scan.

## Alignment grid

- Align titles, values, form labels, tables, and section edges to a small number of shared vertical guides.
- Repeated misalignment is more damaging than small differences in decoration.
- Prefer shared shell/content edges over page-local offsets.
- Numeric columns should use stable alignment and tabular figures where supported.
- In RTL layouts, verify visual reading order rather than mechanically mirroring an LTR mockup.

## Width and density

- Use full workspace width for operational tables, planning, reconciliation, and dashboards where comparison benefits from space.
- Keep prose, help, and long-form explanations at a readable measure inside the wider shell.
- Avoid marketing-style narrow max-width containers on operational pages.
- Do not stretch short forms so far that related fields lose proximity.
- Density is task-specific: accounting can be compact; overview and 360 pages can breathe more.

## Grouping without card inflation

Use, in order:
1. spacing,
2. alignment,
3. typography,
4. subtle separators/background changes,
5. cards only when a true independent object or boundary exists.

A card is justified for a self-contained object, movable/interactive unit, clearly distinct status block, or reusable KPI unit. It is not the default wrapper for every section.

## Balance

- Keep the primary work visually dominant over sidebars.
- Avoid two equally strong columns unless the task genuinely requires comparison.
- Sidebars should contain supporting context, not a second competing primary workflow.
- Keep actions close to the information they affect.
- Reserve large empty space only when it improves comprehension or focus, not to imitate consumer-product minimalism.

## Scan test

Test the composition at:
- 3-second glance;
- normal working distance;
- long Persian labels;
- large numbers;
- several warnings;
- loading;
- empty state;
- compact viewport.

At a glance, the user should identify: where they are, current state, important exception, and next action.
