# Writing

Use familiar Persian business terms, not DocType, table, field, or API names. A label names the exact action or value. Keep action terms stable throughout the flow; replace generic «ارسال» or «ثبت» when the actual outcome is more specific. Error text says what happened, why if known, and how to recover. Empty states offer an appropriate next action.

Use short, direct copy. Match Persian digits, dates, currency, and units to existing formatters. Warn plainly about irreversible or data-sensitive consequences. Do not promise success before the server confirms it.
