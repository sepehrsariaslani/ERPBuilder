# Typography craft

Typography is the primary hierarchy tool in Hesabyar. Use the established Persian type family and token roles; do not add a new font merely for personality.

## Roles before sizes

Define and reuse semantic roles:
- page title / entity identity;
- section title;
- primary value;
- body / operational text;
- label;
- metadata / helper text;
- table header;
- status/action text.

Do not create arbitrary one-off font sizes for each page.

## Persian readability

- Choose weights that remain clear at small sizes; avoid overly thin Persian text in operational UI.
- Give Persian body text enough line height for ascenders/descenders and mixed Persian/Latin values.
- Avoid all-caps-like visual treatment for Latin identifiers when mixed with Persian if it damages rhythm.
- Keep technical IDs visually secondary unless the user's task depends on them.
- Do not truncate important party names, document identities, or exceptions without an intentional reveal path.

## Numeric craft

Amounts, quantities, rates, times, and percentages need stronger discipline:
- use tabular figures when the current font/token stack supports them;
- align comparable numeric columns consistently;
- keep currency/unit visually attached to the value;
- make decimal precision reflect business meaning, not visual convenience;
- distinguish primary amount from supporting metadata with weight/size, not decorative cards alone.

## Hierarchy

Prefer hierarchy through:
1. size,
2. weight,
3. spacing,
4. placement,
5. semantic color only when meaning exists.

Avoid using several bold weights, several text colors, and several sizes in the same small region.

## Contrast and quiet text

Secondary text may be quieter but must remain readable. Do not reduce contrast merely to make the interface look elegant. Disabled, read-only, placeholder, helper, and metadata states must remain visually distinguishable from each other.

## Signature through type

Brand personality can appear through:
- careful title scale;
- strong numeric treatment;
- consistent Persian punctuation;
- tabular data rhythm;
- a restrained display treatment on rare overview moments.

Navigation, forms, and frequent controls remain conventional and highly readable.
