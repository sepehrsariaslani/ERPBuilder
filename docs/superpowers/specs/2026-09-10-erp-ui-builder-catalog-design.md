# طراحی کاتالوگ کم‌هزینهٔ ERP UI Builder

## هدف

مهارت کامل `erp-ui-builder` بدون خلاصه‌سازی منتشر شود و عامل بتواند پیش از بازکردن کد، کامپوننت و صفحهٔ مناسب را با خروجی کوتاه پیدا کند.

## ساختار انتشار

- پوشهٔ `erp-ui-builder/` نسخهٔ کامل مهارت، فایل پیکربندی عامل، کاتالوگ فعلی و اسکریپت‌های آن را نگه می‌دارد.
- `references/directory-map.md` نقشهٔ سطح‌بالای مسیرهای صفحه، کامپوننت، سرویس و طراحی را ارائه می‌کند.
- `references/component-guide.md` راهنمای انسانیِ کامپوننت‌های رسمی و پرتکرار است: زمان استفاده، مسیر، جایگزین نامناسب و روش استفادهٔ کوتاه.
- `references/component-index.json` فهرست کم‌حجم و ماشین‌خوانِ همهٔ کامپوننت‌های Vue را با نام، مسیر و حوزه نگه می‌دارد؛ این فایل برای یافتن مسیر است، نه جایگزین خواندن کد کامپوننت.
- `scripts/find-ui-component.sh` نام یا عبارت جست‌وجو را دریافت می‌کند و فقط مدخل‌های هم‌خوان، راهنمای مرتبط و مسیرهای نزدیک را چاپ می‌کند.

## رفتار مهارت

پیش از جست‌وجوی گسترده یا بازکردن فایل، عامل `find-ui-component.sh` را اجرا می‌کند. سپس فقط راهنمای مرتبط و در صورت نیاز فایل انتخاب‌شده را می‌خواند. اگر نتیجه‌ای وجود نداشت، از `scan-ui-context.sh` برای حوزهٔ مالک استفاده می‌کند.

## نگهداری و ایمنی

- فهرست همهٔ کامپوننت‌ها مسیر و حوزه را ثبت می‌کند، اما برای همهٔ آن‌ها مستندات بلند تولید نمی‌شود؛ راهنمای کامل فقط برای primitiveها و الگوهای رسمی است.
- اسکریپت‌ها فقط خواندنی هستند و هیچ فایل پروژه را تغییر نمی‌دهند.
- در راهنما تأکید می‌شود که کاتالوگ جای API واقعی کامپوننت نیست؛ برای props، events یا slotهای ناشناخته فقط همان فایل انتخاب‌شده باز می‌شود.

## بررسی

- آزمون اسکریپت برای تطبیق دقیق، تطبیق جزئی و نتیجهٔ ناموجود.
- اعتبارسنجی JSON و بررسی وجود همهٔ مسیرهای ثبت‌شده در کاتالوگ.
- بررسی کپی کامل فایل‌های مهارت و خوانایی راهنمای نصب.
